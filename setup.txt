Redis (required for cache, seat locks, and WebSockets)
Install the Memurai Windows service from https://www.memurai.com/get-memurai.
In the installer, keep the Windows service option enabled and use port 6379.

Check that Redis is ready (PONG means it is working):
& "C:\Program Files\Memurai\memurai-cli.exe" ping

If the service is stopped, start it from an elevated PowerShell:
Start-Service Memurai

Keep REDIS_HOST=127.0.0.1 and REDIS_PORT=6379 in Ticket\.env when running Django on this computer.
